# Industrial Recrafted

Welcome to the Industrial Recrafted.

This mod is a remake of an old classic tech mod.

## World Generation

### Ores

The mod adds a total of 3 new ores to stone and deepslate layers

Tin is used early on for many of the basic items, blocks and machines. Uranium is mainly useful for the <ItemImage id="indrec:nuclear_reactor" scale="0.5" /> Nuclear Reactor and Iridium is the endgame material used to construct the most powerful gadgets like the <ItemImage id="indrec:quantum_chestplate" scale="0.5" /> Quantum Armor

### Rubber Trees

Rubber Trees are trees that generate in all biomes and have special "Resin Spots" than can be harvested using a <ItemImage id="indrec:treetap" scale="0.5" />Tree Tap for <ItemImage id="indrec:sticky_resin" scale="0.5" /> Sticky Resin. Sticky Resin is used to produce <ItemImage id="indrec:rubber" scale="0.5" /> Rubber, which is an essential component for most Cables and Machinery.

### Loot

Many basic components like <ItemImage id="indrec:redstone_battery" scale="0.5" /> Redstone Batteries, <ItemImage id="indrec:basic_circuit" scale="0.5" /> Basic Circuits, <ItemImage id="indrec:refined_iron_ingot" scale="0.5" /> Refined Iron Ingot... can be found in dungeon and village chests.
